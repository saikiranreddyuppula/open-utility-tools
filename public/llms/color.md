# Color

> Pick, convert & generate color

72 tools. Each runs entirely in the browser.

Hub: https://www.openutilitytools.com/categories/color/

## Tools

- [Accessible Contrast Fixer](https://www.openutilitytools.com/tools/color-contrast-suggester/): Adjust a foreground color's lightness until it meets a WCAG contrast target.
- [Accessible Text Color Picker](https://www.openutilitytools.com/tools/accessible-text-color/): Decide whether black or white text is more readable on any background color.
- [Alpha Blend Over Background](https://www.openutilitytools.com/tools/alpha-blend-over-background/): Compute the solid opaque color produced by a translucent color over a background.
- [Analogous Color Scheme Generator](https://www.openutilitytools.com/tools/analogous-color-scheme/): Create harmonious neighboring-hue palettes around a base color.
- [ANSI 256-Color to RGB](https://www.openutilitytools.com/tools/color-ansi-256-to-rgb/): Map xterm 256-color palette indices to RGB hex and back to the nearest index.
- [Average & Dominant Color from List](https://www.openutilitytools.com/tools/color-image-free-dominant-from-hexlist/): Computes the arithmetic mean color and most frequent color from a list of hex colors.
- [Box Shadow Generator](https://www.openutilitytools.com/tools/box-shadow-generator/): Visually design CSS box-shadows by adjusting offset, blur, spread, color, and inset, then copy the ready-to-use box-shadow rule.
- [Color Blend Mode Calculator](https://www.openutilitytools.com/tools/color-blend-modes-calculator/): Compute the result of blending two colors with Photoshop-style blend modes.
- [Color Blindness Simulator](https://www.openutilitytools.com/tools/color-blindness/): Preview how a color appears under common color-vision deficiencies.
- [Color Converter](https://www.openutilitytools.com/tools/color-converter/): Convert colors between HEX, RGB, HSL, HSV, CMYK and OKLCH, with a live preview.
- [Color Difference (Delta-E)](https://www.openutilitytools.com/tools/color-distance-deltae/): Measure how different two colors are using CIE76, CIE94, and CIEDE2000.
- [Color Harmony / Palette Builder](https://www.openutilitytools.com/tools/color-harmony/): Build harmonious palettes from a base color using complementary, analogous, triadic, tetradic, split-complementary, and monochromatic schemes.

- [Color List Sorter](https://www.openutilitytools.com/tools/color-sort-by-hue/): Sort a pasted list of colors by hue, lightness, saturation, or luminance.

- [Color Name Finder](https://www.openutilitytools.com/tools/color-name-finder/): Find the closest human-readable color name (like 'cornflower blue') for any HEX or RGB value using the CSS named color set.

- [Color Shade Namer](https://www.openutilitytools.com/tools/color-shade-namer/): Generate a human-readable descriptive name for any color from its HSL.
- [Color Temperature (Kelvin) Converter](https://www.openutilitytools.com/tools/kelvin-to-rgb/): Convert a color temperature in Kelvin to its approximate RGB/HEX color, useful for lighting, white balance, and warm/cool tone work.
- [Color Temperature Shift](https://www.openutilitytools.com/tools/color-temperature-shift/): Warm or cool a color by shifting it toward a target white point.
- [Color Tints Generator](https://www.openutilitytools.com/tools/color-tints-generator/): Generate a row of lighter tints by mixing a base color toward white.
- [Color Tones Generator](https://www.openutilitytools.com/tools/color-tones-generator/): Generate muted tones by mixing a base color toward a neutral gray.

- [Contrast Ratio Grid](https://www.openutilitytools.com/tools/contrast-ratio-grid/): Build an N x N WCAG contrast matrix for a set of palette colors.

- [CSS Gradient Parser](https://www.openutilitytools.com/tools/color-css-gradient-extract-stops/): Parses a CSS linear/radial gradient string into structured angle, type, and color stops.
