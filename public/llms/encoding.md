# Encoding

> Base64, hex, URL, compression & more

54 tools. Each runs entirely in the browser.

Hub: https://www.openutilitytools.com/categories/encoding/

## Tools

- [ASCII / Code Point Converter](https://www.openutilitytools.com/tools/encoding-ascii-code-point/): Convert text to ASCII/Unicode code point numbers and convert numeric lists back to text.
- [ASCII ↔ EBCDIC Converter](https://www.openutilitytools.com/tools/encoding-ebcdic-converter/): Convert text between ASCII/Latin-1 and IBM EBCDIC code pages, byte for byte.
- [Ascii85 / Base85 Encode](https://www.openutilitytools.com/tools/ascii85/): Encode and decode text using Ascii85 (Adobe variant).
- [Base16 Encode / Decode](https://www.openutilitytools.com/tools/encoding-base16-encode/): Encode text to uppercase Base16 (RFC 4648 hex) and decode it back, with strict validation.
- [Base32 Encode / Decode](https://www.openutilitytools.com/tools/base32-text/): Encode text to RFC 4648 Base32 and decode it back.
- [Base32hex (Extended Hex) Encode / Decode](https://www.openutilitytools.com/tools/encoding-base32hex-encode/): Encode/decode using the RFC 4648 Base32hex extended-hex alphabet (0-9A-V).
- [Base36 Encode / Decode](https://www.openutilitytools.com/tools/encoding-base36-encode/): Convert between arbitrary-length integers and Base36 (0-9, a-z) strings.
- [Base45 Encode / Decode](https://www.openutilitytools.com/tools/encoding-base45/): Encode text to RFC 9285 Base45 or decode Base45 back to text, as used in QR-code data payloads.
- [Base58 Encode / Decode](https://www.openutilitytools.com/tools/base58/): Encode bytes/text to Base58 (Bitcoin alphabet) and decode it back.
- [Base62 Encode / Decode](https://www.openutilitytools.com/tools/encoding-base62-encode/): Encode bytes or big integers to Base62 (0-9A-Za-z) and decode back, like short-URL IDs use.
- [Base64 / Data URI Image Inspector](https://www.openutilitytools.com/tools/encoding-base64-image-inspector/): Decode a Base64 or data: URI image string and report its real format, dimensions, and size.
- [Base64 ↔ Base32 Cross Converter](https://www.openutilitytools.com/tools/encoding-base64-base32-cross/): Directly transcode between Base64 and Base32 representations of the same bytes without manual decode/encode.
- [Base64 Encode / Decode](https://www.openutilitytools.com/tools/base64-text/): Encode text to Base64 (standard or URL-safe) and decode it back — live.
- [Base64 Image / Data URI Builder](https://www.openutilitytools.com/tools/encoding-data-uri-builder/): Wrap Base64 content into a data: URI with a chosen MIME type, or extract the MIME and decoded payload from an existing data URI.
- [Base64 to Hex Converter](https://www.openutilitytools.com/tools/encoding-base64-to-hex/): Convert between Base64-encoded data and its hexadecimal byte representation in both directions.
- [Base64 URL-Safe Encode / Decode](https://www.openutilitytools.com/tools/encoding-base64url/): Encode or decode text using the URL-safe Base64 alphabet with optional padding for tokens and URLs.
- [Base85 (RFC 1924 / ZeroMQ) Variants](https://www.openutilitytools.com/tools/encoding-base85-rfc1924/): Encodes and decodes data across Base85 alphabets: ASCII85, RFC 1924, and Z85 side by side.
- [basE91 Encode / Decode](https://www.openutilitytools.com/tools/encoding-base91-encode/): Encode binary text to basE91, a denser ASCII encoding than Base64.
- [Braille (Unicode) Translator](https://www.openutilitytools.com/tools/encoding-braille-converter/): Convert printable text to and from Unicode Braille patterns (Grade 1).
- [Caesar Cipher Shift](https://www.openutilitytools.com/tools/encoding-caesar-cipher/): Encode or decode text with a configurable Caesar shift, rotating letters by any amount while preserving case and symbols.
- [Char Multi-Radix Encoder (Dec/Bin/Oct/Hex)](https://www.openutilitytools.com/tools/encoding-decimal-binary-octal-hex/): Show every character's value simultaneously in decimal, binary, octal, and hex.
- [Code Point ↔ UTF-8/UTF-16 Bytes](https://www.openutilitytools.com/tools/encoding-codepoint-utf-converter/): Convert Unicode code points to their UTF-8 and UTF-16 byte encodings and back.
- [CSV Field Escaper / Unescaper](https://www.openutilitytools.com/tools/encoding-csv-field-escape/): Escape a single value for safe CSV embedding (RFC 4180 quoting) and unescape a CSV field.
- [Gzip Base64 Compress / Decompress](https://www.openutilitytools.com/tools/encoding-gzip-base64/): Compress text with gzip and output Base64, or decode Base64 gzip back to the original text.
- [Hex Encode / Decode](https://www.openutilitytools.com/tools/hex-text/): Convert text to hexadecimal and back, with optional uppercase.
- [HTML Entity Encode / Decode](https://www.openutilitytools.com/tools/html-entities/): Escape text to HTML entities and unescape entities back to text.
- [HTML Named ↔ Numeric Entity Converter](https://www.openutilitytools.com/tools/encoding-html-named-numeric/): Convert HTML named entities to and from their decimal and hexadecimal numeric character references, both ways.
- [JavaScript String Escaper / Unescaper](https://www.openutilitytools.com/tools/encoding-js-string-escape/): Escape arbitrary text into a safe JS string literal and unescape it back.
- [JSON Pointer Escaper (RFC 6901)](https://www.openutilitytools.com/tools/encoding-json-pointer-escape/): Encode and decode JSON Pointer reference tokens with the ~0/~1 escape rules.
- [JWT Decoder & Inspector](https://www.openutilitytools.com/tools/encoding-jwt-inspector/): Decode a JSON Web Token into its readable header and payload claims, with human-friendly timestamps for exp/iat/nbf.
- [Numeric HTML Character References](https://www.openutilitytools.com/tools/encoding-numeric-char-references/): Convert text into numeric HTML character references (decimal or hex) and decode them back to plain text.
- [Octal Encode / Decode](https://www.openutilitytools.com/tools/encoding-octal-text/): Encode UTF-8 text to space-separated octal byte values or decode octal numbers back into readable text.
- [Percent-Encoding Reference Table](https://www.openutilitytools.com/tools/encoding-percent-encoding-table/): Searchable table of percent-encoded (%XX) values for ASCII and common reserved characters.
- [Protobuf Binary Decoder](https://www.openutilitytools.com/tools/protobuf-binary-decoder/): Decode protobuf wire bytes into field numbers, wire types, and raw scalar values.
- [Punycode Encode / Decode](https://www.openutilitytools.com/tools/encoding-punycode/): Convert internationalized domain names to ASCII Punycode (xn--) and back to their Unicode form.
- [Quoted-Printable Encode / Decode](https://www.openutilitytools.com/tools/encoding-quoted-printable/): Encode text to MIME quoted-printable or decode quoted-printable email content back to text.
- [Regex Special-Character Escaper](https://www.openutilitytools.com/tools/encoding-regex-literal-escape/): Escape text so it matches literally inside a regular expression, for several flavors.
- [ROT-N Cipher (Custom Rotation)](https://www.openutilitytools.com/tools/encoding-rot-n-cipher/): Apply a Caesar-style rotation with any shift 0-25, with brute-force preview of all shifts.
- [Shell Argument Escaper / Quoter](https://www.openutilitytools.com/tools/encoding-shell-arg-escape/): Safely quote text as a single shell argument for POSIX sh/bash or PowerShell.
- [SQL String Escaper](https://www.openutilitytools.com/tools/encoding-sql-string-escape/): Escape text into a safe SQL string literal for common database dialects.
- [Text to Binary](https://www.openutilitytools.com/tools/binary-text/): Convert text to its binary (and back), with a configurable separator.
- [Unicode Confusables / Homoglyph Detector](https://www.openutilitytools.com/tools/encoding-unicode-confusables-detector/): Detect and normalize visually deceptive lookalike characters in text.
- [Unicode Escape / Unescape](https://www.openutilitytools.com/tools/encoding-unicode-escape/): Convert characters to \uXXXX escape sequences or unescape them back to readable Unicode text.
- [Unicode Normalization (NFC/NFD/NFKC/NFKD)](https://www.openutilitytools.com/tools/encoding-unicode-normalization/): Apply and compare the four Unicode normalization forms to text.
- [URI Template Expander (RFC 6570)](https://www.openutilitytools.com/tools/encoding-uri-template-expander/): Expand RFC 6570 URI templates with variables, applying correct percent-encoding per operator.
- [URL Encode / Decode](https://www.openutilitytools.com/tools/url-encode/): Percent-encode and decode text or whole-component URL strings.

- [UTF-8 Byte Inspector](https://www.openutilitytools.com/tools/encoding-utf8-byte-inspector/): Break text into its UTF-8 byte sequence with per-character hex, binary, and code points.
- [UUencode / UUdecode](https://www.openutilitytools.com/tools/encoding-uuencode/): Encode and decode data in the classic Unix uuencode format.
- [Uuencode / Xxencode Converter](https://www.openutilitytools.com/tools/encoding-uuencode-xxencode/): Encodes and decodes data using classic Unix uuencode and xxencode formats.
- [XOR Cipher (Text)](https://www.openutilitytools.com/tools/encoding-xor-cipher/): Encrypt or decrypt text with a repeating-key XOR cipher, outputting or reading hex or Base64.
- [XXencode / XXdecode](https://www.openutilitytools.com/tools/encoding-xxencode/): Encode and decode using the XXencode alphabet (a safer uuencode variant).
- [Z85 Encode / Decode](https://www.openutilitytools.com/tools/encoding-z85-encode/): Encode/decode using ZeroMQ Z85, a printable Base85 variant safe for source code.
