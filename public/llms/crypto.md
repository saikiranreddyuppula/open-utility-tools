# Crypto & Hash

> Hashes, HMAC, JWT, keys & ciphers

68 tools. Each runs entirely in the browser.

Hub: https://www.openutilitytools.com/categories/crypto/

## Tools

- [/etc/passwd & shadow Parser](https://www.openutilitytools.com/tools/crypto-passwd-shadow-parser/): Parse and explain Unix passwd and shadow file lines field by field.
- [ABA Routing Number Validator](https://www.openutilitytools.com/tools/aba-routing-validator/): Validate a US bank ABA/routing transit number using its mod-10 checksum.
- [Adler-32 Checksum](https://www.openutilitytools.com/tools/adler32-checksum/): Compute the Adler-32 checksum of text or a file, as used by zlib.
- [AES Encrypt / Decrypt](https://www.openutilitytools.com/tools/aes-encrypt-decrypt/): Encrypt and decrypt text with AES-GCM using a passphrase, producing self-contained Base64 output with embedded salt and IV.
- [AES-CBC Text Encrypt/Decrypt](https://www.openutilitytools.com/tools/aes-cbc-text/): Encrypt or decrypt text with AES-CBC using a passphrase-derived key and explicit IV.
- [AES-GCM File Encrypt/Decrypt](https://www.openutilitytools.com/tools/aes-gcm-file/): Encrypt or decrypt a chosen file in-browser with AES-GCM using a passphrase.
- [API Key + Secret Generator](https://www.openutilitytools.com/tools/api-key-pair-generator/): Generate matched public key ID and secret pairs with prefixes and a derived checksum.
- [Argon2 Parameter Advisor](https://www.openutilitytools.com/tools/crypto-argon2-params-advisor/): Recommend Argon2id memory, iteration, and parallelism parameters for a target environment.
- [Australian BSB Lookup](https://www.openutilitytools.com/tools/bsb-validator/): Validate and parse an Australian Bank State Branch (BSB) number into bank, state, and branch.
- [Base64url JWK Field Encoder](https://www.openutilitytools.com/tools/base64url-jwk-encoder/): Convert between Base64url and big-integer/byte values for hand-editing JWK fields.
- [Bcrypt Cost Estimator](https://www.openutilitytools.com/tools/crypto-bcrypt-cost-benchmark/): Estimate bcrypt hashing time for each cost factor and recommend a target work factor.
- [Bcrypt Hash & Verify](https://www.openutilitytools.com/tools/bcrypt/): Hash a password with bcrypt and verify a password against a hash, locally.
- [BIP39 Mnemonic Generator](https://www.openutilitytools.com/tools/bip39-mnemonic-generator/): Generate BIP39 seed phrases of 12, 15, 18, 21, or 24 words with a valid checksum for crypto wallet backups.
- [Certificate Chain Builder](https://www.openutilitytools.com/tools/certificate-chain-builder/): Inspect pasted PEM certificate chains and flag ordering, duplicate subjects, and missing intermediates.
- [CRC32 Checksum](https://www.openutilitytools.com/tools/crc32-checksum/): Compute the CRC-32 checksum of any text, output as hex or unsigned decimal for quick integrity checks.
- [CSR Generator & Validator](https://www.openutilitytools.com/tools/csr-generator-validator/): Generate an OpenSSL CSR command and inspect pasted CSR PEM blocks.
- [Diceware Passphrase Generator](https://www.openutilitytools.com/tools/diceware-passphrase/): Generate memorable passphrases from a bundled Diceware-style 7776-word list using cryptographic randomness.
- [EAN / UPC Check Digit](https://www.openutilitytools.com/tools/ean-upc-check-digit/): Validate or compute check digits for EAN-13, EAN-8, and UPC-A barcodes.
- [ECDSA Key Pair Generator](https://www.openutilitytools.com/tools/ecdsa-keypair-generator/): Generate an elliptic-curve (P-256/P-384/P-521) key pair as PEM for ECDSA signing.
- [ECDSA Sign & Verify](https://www.openutilitytools.com/tools/ecdsa-sign-verify/): Sign and verify messages with ECDSA over P-256/P-384/P-521 curves.
- [File Hash](https://www.openutilitytools.com/tools/file-hash/): Hash any local file with MD5, SHA-1, SHA-256, or SHA-512 by dropping it in, with a field to compare against an expected checksum.
- [Fletcher-16/32/64 Checksum](https://www.openutilitytools.com/tools/fletcher-checksum/): Compute Fletcher checksums (16, 32, and 64-bit) of input bytes.
- [Hash Compare & Verify](https://www.openutilitytools.com/tools/hash-compare-verify/): Paste an expected checksum and your text or file hash to confirm they match with constant-time-style comparison.
- [Hash Text](https://www.openutilitytools.com/tools/hash-text/): Compute MD5, SHA-1, SHA-256/384/512, SHA-3, BLAKE3 and CRC32 digests of text — live, in your browser.
- [HKDF Key Derivation](https://www.openutilitytools.com/tools/hkdf-key-derivation/): Expand input key material into one or more output keys using HKDF (RFC 5869).
- [HMAC Generator](https://www.openutilitytools.com/tools/hmac-generator/): Compute HMAC (SHA-1/256/384/512) of a message with a secret key.
- [HMAC Verify](https://www.openutilitytools.com/tools/hmac-verify/): Recompute an HMAC over a message and key, then compare it against an expected MAC to verify authenticity.
- [IBAN Validator](https://www.openutilitytools.com/tools/iban-validator/): Validate an IBAN using the ISO 13616 mod-97 checksum and show its structure.
- [ISBN-10 / ISBN-13 Validator](https://www.openutilitytools.com/tools/isbn-validator/): Validate ISBN-10 and ISBN-13 check digits and convert between the two formats.
- [JWK / PEM Key Viewer](https://www.openutilitytools.com/tools/jwk-pem-viewer/): Inspect and convert between JWK and PEM key representations and display their parameters.
- [JWK Rotation Diff](https://www.openutilitytools.com/tools/jwk-rotation-diff/): Compare old and new JWKS documents and identify added, removed, and changed keys.
- [JWK Thumbprint (RFC 7638)](https://www.openutilitytools.com/tools/jwk-thumbprint/): Compute the canonical SHA-256 thumbprint of a JSON Web Key per RFC 7638.
- [JWKS Inspector](https://www.openutilitytools.com/tools/jwks-inspector/): Inspect JSON Web Key Sets, key IDs, algorithms, use, key type, and rotation readiness.
- [JWT Builder (RS/ES)](https://www.openutilitytools.com/tools/jwt-builder-rsa-es/): Build and sign JSON Web Tokens with RSA or ECDSA keys (RS256/384/512, ES256/384/512, PS256).
- [JWT Claims Validator](https://www.openutilitytools.com/tools/jwt-claims-validator/): Decode a JWT and check its registered claims (exp, nbf, iat, aud, iss) without verifying the signature.
- [JWT Generator](https://www.openutilitytools.com/tools/jwt-generator/): Create a signed HS256/384/512 JSON Web Token from a payload and secret.
- [JWT Signature Verifier (HS256)](https://www.openutilitytools.com/tools/jwt-verify-hmac/): Verify an HMAC-signed JWT (HS256/384/512) against a secret and report whether the signature and expiry are valid.
- [JWT Verifier (RS/ES)](https://www.openutilitytools.com/tools/jwt-verify-rsa-es/): Verify a JWT signature against an RSA or ECDSA public key and check standard claims.
- [KDF Parameter Planner](https://www.openutilitytools.com/tools/scrypt-style-kdf-params/): Compute memory, time, and output sizes for PBKDF2/scrypt/Argon2 parameter sets without running them.
- [Key Fingerprint Generator](https://www.openutilitytools.com/tools/crypto-key-fingerprint/): Compute SSH-style and certificate-style fingerprints of a public key (MD5 colon-hex and SHA-256 base64).
- [Luhn Checksum Validator](https://www.openutilitytools.com/tools/luhn-validator/): Validate any Luhn-based number (credit cards, IMEI, etc.) and compute its check digit.
- [MD5 Hash Generator](https://www.openutilitytools.com/tools/md5-hash/): Generate the MD5 hash of any text, with lowercase or uppercase hex output (the algorithm Web Crypto omits).
- [Mod-10 / Mod-11 Check Digit Calculator](https://www.openutilitytools.com/tools/crypto-mod10-mod11-check-digit/): Computes and verifies Mod-10 (Luhn) and Mod-11 check digits for arbitrary numeric strings.
- [Multi-Algorithm Text Checksum](https://www.openutilitytools.com/tools/crypto-text-checksum-multi/): Computes CRC-8, CRC-16, CRC-32, Adler-32 and a simple XOR/sum checksum of text in one view.

- [OTPAuth URI & QR Builder](https://www.openutilitytools.com/tools/otp-uri-builder/): Build otpauth:// provisioning URIs for TOTP/HOTP authenticator apps from a Base32 secret and render a scannable QR code.

- [Password Generator](https://www.openutilitytools.com/tools/password-generator/): Generate strong random passwords or diceware passphrases, locally.
